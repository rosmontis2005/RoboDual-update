# Meeting 0804：实验分步成功率汇总

## 口径

主表覆盖 `evaluation_results` 中有完整 `result_rank0.json` 和 100 条序列记录的结果：非 LoRA 实验全部保留；LoRA 选择 V2、V3、V4、V7（gate age 8）和 V11（gate age 12）作为代表。所有主表行的评测规模均为 `N=100`。

- 分步成功率 `S_i`：直接读取评测输出中的 `chain_sr[i]`，表示一条序列至少连续完成前 `i` 个 subtask 的比例。
- 相对成功率 `R_i`：在已经完成前一个 subtask 的条件下，第 `i` 个 subtask 继续成功的概率：`R_1=S_1`，`R_i=S_i/S_{i-1}`。
- 每个 subtask 的条件失败概率 `F_i`：`F_i=1-R_i`。因此表中的 `F_i` 是“已经到达该 subtask 后，在该 subtask 失败”的概率；分母为 0 时记为 `—`。
